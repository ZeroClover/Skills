# Repetition

Source: Robin Williams, *The Non-Designer's Design Book*, 4th edition, Chapter 4, "Repetition." Repeat some visual aspect through the whole piece so separate parts read as one design. Repetition unifies the piece and adds interest. On a single page it ties the clusters together. Across pages it is what makes page 3 and page 13 the same publication. Consistency is the start. Conscious repetition pushes that consistency until a reader can see it.

## Rules

Find the repetition you already have and strengthen it. Headings that share a size become a stronger tie when they also share a distinctive face, weight, or color. A hairline under every heading becomes a tie when it is heavy enough to notice.

Repeat on purpose. Useful repeats include a type style, a color, a rule weight, a bullet, a corner treatment, an icon style, and a spatial relationship (the same space above every heading, the same margin).

The repeated items can vary and still belong together. A set of headings in one face and several colors still repeats the face. A family of illustrations in different drawings still repeats if they share a weight and a palette. The family has to be obvious.

Use repetition to steer the eye. A bold treatment at the start and a bold treatment at the end of a card pulls attention back onto the card.

Stop before the repeat becomes the whole design. If every element carries the accent color, nothing is accented. Williams' illustration is a black dress with a red shoe and a red pin, against the same dress covered in red. The first is repetition. The second loses the focus.

On a multi-page or multi-screen piece, repeat the placement of page-level elements: the header rule, the page number or step indicator, the heading style, and the content start line. Pick either a consistent top alignment or a consistent bottom alignment and keep it.

Save a break in the pattern for the item that must stand out. A surprise only works when the surrounding pattern is strong.

## Examples

**Do.** A three-step checkout where each step uses the same number treatment, the same heading face, and the same primary button. The current step adds a second cue, a filled number and a heavier label, so the repeat still holds and the current step is obvious.

**Avoid.** Step 1 in a serif, step 2 in a different sans, step 3 in underlined bold, each with a different button shape. The steps are one process and look like three products. A second avoid: the brand color on the background, the headings, the body links, the icons, and the button, so the button disappears.

## Review questions

- Which element already repeats, and is it strong enough to notice?
- Would a reader know that screen 2 and screen 6 belong to the same product?
- Can the repeated element vary and still look related?
- Has the accent been used so often that it no longer points at anything?
- Is the one break in the pattern reserved for the item that matters most?
